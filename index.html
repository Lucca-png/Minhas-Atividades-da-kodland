neste tutorial vamos baixar o homelab-base

siga todos os passos

neste tutorial tem

  • instalação do sistema
  • configurando o sistema e baixando a repo
  • baixando apps
  • windows 11 VM

Requisitos

  • 2 PC, um para o ser o servidor, e outro para fazer a conecção via sh
  • Um usb de 8Gb para a instalação
  • Uma boa internet (se possivel)
  • um bom armazenamento
  • Uma conta no github
  • Instalação do sistema

1. Instale o ubuntu server com open ssh

2. Faça login e conecte ao seu servidor via ssh e aualize o sistema

  • Configurando o sistema e baixando a repo

no github va em

https://github.com/andresvidoza/homelab-base

e clique no botão fork

Ele vai criar uma copia na sua conta do github, após isso, clone o repositorio no seu servidor com

git clone https://github.com/andresvidoza/homelab-base

agora execute :

cd homelab-base

cd cloud-init

nano user-data.example

e complete as informações com usuario, chave ssh publica e o fork que fizermos mais cedo
